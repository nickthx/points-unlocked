## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-12 | Denial of service / Tampering | joinAdvisorWaitlist spam + enumeration | mitigate | Hidden honeypot `website` returns success without writing; `interestSchema` caps length at 254 and validates format; `email` UNIQUE + `onConflictDoNothing` makes repeats idempotent and returns the same success copy (no "already registered" oracle); Vercel platform rate limits; Phase 7 may add WAF rules |
| T-05-13 | Information disclosure | DB driver in client bundle | mitigate | `src/app/actions/interest.ts` (`"use server"`) is the sole `@/db` importer under `src/app` + `src/components`; `advisor-tease.tsx` imports only the action reference; grep gate asserts exactly one path |
| T-05-14 | Information disclosure | Action error path / logs | mitigate | zod issue text never returned (can echo input); bare `catch {}` returns fixed neutral copy; no `console.*` of the caught driver error (may embed connection info); no PII in any returned message |
| T-05-15 | Information disclosure | drizzle-kit push / db-check | mitigate | Env loaded from gitignored `.env.development.local`; commands never print the URL; `git check-ignore` + `git status` asserted in Task 1 (T-02-10 / T-01-08 precedent) |
| T-05-16 | Repudiation | interest_signups PII retention | accept | Pre-launch capture with visible consent microcopy (A4); Phase 6 privacy policy + deletion path covers it; `source` + `created_at` columns give an audit trail |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No packages installed this phase |
