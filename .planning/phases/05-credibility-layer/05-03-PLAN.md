<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Crawler/visitor → GET /og?params | Untrusted query string parsed into balances and rendered into a PNG |
| Crawler/visitor → GET /?params | Untrusted query string parsed into `<head>` meta tags |
| Vercel CDN cache | Per-URL cached PNGs served to every subsequent requester |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | Tampering | src/app/og/route.tsx query parsing | mitigate | `loadBalanceParams(request)` (parseAsInteger) → `paramsToBalances` (positive safe integers only) → engine `sanitizeBalances` — the same triple layer as the page (T-04-10); unknown keys, arrays, floats, negatives drop; rendered text comes only from `buildShareContent` (T-05-01) |
| T-05-08 | Denial of service | /og CPU | mitigate | Input collapses to ≤ 8 bounded integers; engine search is bounded (T-03-05); `Cache-Control: public, s-maxage=86400, stale-while-revalidate=604800` makes the CDN absorb repeats; PNG ~40–60 KB; fonts read once per process |
| T-05-09 | Information disclosure | /og error path | mitigate | Bare `catch {}` returns `Response("Image unavailable", 500)` with no error text and no logging (T-01-07 precedent) |
| T-05-10 | Spoofing | metadataBase host | mitigate | Fixed production constant with optional `NEXT_PUBLIC_SITE_URL` override; never `VERCEL_URL` (protected preview host → 401 for crawlers, wrong canonical) — grep-gated |
| T-05-11 | Tampering | og:url / og:image cache keying | mitigate | `og:url` and `og:image` carry the canonical query string from `balancesToParams` order, so distinct balance sets never share a preview; plan 05-05 verifies two param sets yield different PNGs and `x-vercel-cache: HIT` on repeat |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No packages installed this phase (`next/og` is bundled) |
</threat_model>
